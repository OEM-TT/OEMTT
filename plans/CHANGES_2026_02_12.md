## Summary

1. Temporarily disabled Perplexity manual discovery feature
2. Enhanced AI chat with better confidence scoring, Perplexity fallback, and more flexible prompting

## 2. Enhanced AI Chat System

### A. Adjusted Confidence Thresholds

**File:** `backend/src/services/answering/context.ts`

**Changes:**
- Raised manual confidence threshold from **0.65 → 0.70** (more strict about using manual content)
- Adjusted general knowledge threshold from **0.50 → 0.60** for medium confidence
- Increased general knowledge confidence score from **0.55 → 0.60**

**Result:** AI now defaults to general knowledge more readily when manual content isn't highly relevant.

---

### B. Implemented Perplexity Phase 3 Fallback

**New Function:** `answerWithWebSearch()` in `backend/src/services/discovery/perplexity.ts`

**Integration:** `backend/src/controllers/chat.controller.ts`

**How it works:**
1. When confidence is very low (`sourceType === 'needs_web_search'`)
2. System automatically calls Perplexity web search API
3. Returns real-time answer with web citations
4. Streams response to user with sources
5. Saves to database with special type: `perplexity_web_search`

**Fallback flow:**
```
Manual Content (>0.7 confidence)
    ↓ (if not found)
General HVAC Knowledge (0.6-0.7 confidence)
    ↓ (if not applicable)
Perplexity Web Search (<0.6 confidence, model-specific)
    ↓ (if fails)
OpenAI General Knowledge (final fallback)
```

---

### C. Loosened AI System Prompts

**File:** `backend/src/services/answering/context.ts` - `buildSystemPrompt()`

**Major Changes:**

**Before:**
- Strict: "Your ONLY role is to extract information from the manual"
- Required citations for every statement
- Would refuse to answer if manual sections weren't perfect match

**After:**
- Flexible: "Expert HVAC technician using manual content + general knowledge"
- Three-tier approach:
  - **High relevance (>70%):** Use manual as primary source
  - **Medium relevance (50-70%):** Combine manual + general knowledge
  - **Low relevance (<50%):** Use expert HVAC knowledge freely
- Emphasis on being helpful and giving right answer every time
- Smarter citation system (cite when using manual, note when using general knowledge)

**Key Improvements:**
1. **"Always be helpful"** - Don't withhold useful information
2. **Combine sources intelligently** - Manual + experience for complete answers
3. **Context-aware responses** - Adjust approach based on question type
4. **Practical focus** - Actionable advice over strict documentation adherence

## 7.1 Bug Fixes (Post-Implementation)

### Fix 1: React Native Text Rendering Crash
**Issue:** App crashed with "Text strings must be rendered within a <Text> component"
**Root Cause:** `renderSourcesWithClickablePages()` was returning raw string instead of React component
**Fix:** Wrap all return values in proper `<Markdown>` components
**File:** `app/(modals)/unit-chat.tsx` line 289

### Fix 2: Always Use Perplexity for Production/Availability Questions
**Issue:** Questions like "Is this model discontinued?" matched irrelevant keywords ("still" in shipping text) and got high similarity scores, preventing web search
**Root Cause:** Keyword matching was too broad, didn't recognize time-sensitive/external data questions
**Fix:** Added `alwaysWebSearchPatterns` that bypass manual similarity checks for:
- Production status / discontinued
- Latest bulletins/updates
- Recalls & safety notices
- Warranty information
- Pricing & availability
- Replacement models
**File:** `backend/src/services/answering/context.ts` line 522-544

### Fix 3: Make Perplexity Web Sources Clickable
**Issue:** Web sources from Perplexity displayed as plain text URLs instead of clickable links
**Root Cause:** Frontend didn't detect "Sources (from web):" pattern and render URLs as touchable links
**Fix:** 
- Added `Linking` import for opening URLs in browser
- Created `renderWebSources()` function to detect and parse web sources
- Renders each URL as a `TouchableOpacity` that opens in system browser
- Styled with blue background, underline, and external link icon
**File:** `app/(modals)/unit-chat.tsx`
- Line 12: Added Linking import
- Line 278-364: Added renderWebSources function
- Line 1020-1048: Added web source styles
